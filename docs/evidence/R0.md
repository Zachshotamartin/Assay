## Acceptance blocker

The following required controls cannot be enabled for a private repository on
the owning account's current GitHub plan:

- Branch-protection PUT and read-only query return HTTP 403:
  `Upgrade to GitHub Pro or make this repository public to enable this feature.`
- Repository ruleset creation and query for protected `v*` tags return the
  same HTTP 403 plan error.
- Creating the `release` environment succeeded, but adding its required
  reviewer returned HTTP 422; the verified environment has
  `protection_rules: []` and therefore supplies no approval control.
- Because branch protection is absent, the required direct-push rejection
  test cannot truthfully pass.

This is an external governance blocker, not a skipped test. R0 remains **in
progress**, this pull request remains open, and no accepted-gate claim is made.

verify these recorded operations:
