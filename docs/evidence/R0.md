## Governance resolution

The original private-repository plan limitation was resolved by the owner's
explicit instruction to make the portfolio repository public. The live
controls were applied and verified through the authenticated GitHub CLI:

```sh
gh api --method PUT repos/Zachshotamartin/Assay/branches/main/protection --input .github/settings/branch-protection.json
gh api repos/Zachshotamartin/Assay/branches/main/protection
gh api --method PUT repos/Zachshotamartin/Assay/environments/release --input .github/settings/release-environment.json
gh api repos/Zachshotamartin/Assay/environments/release
gh api --method POST repos/Zachshotamartin/Assay/rulesets --input .github/settings/version-tag-ruleset.json
gh api repos/Zachshotamartin/Assay/rulesets
```

The branch-protection source payload uses the API's modern `checks` form only;
sending both deprecated `contexts` and `checks` returned HTTP 422, so the
redundant empty `contexts` member was removed without changing any required
check. Read-only queries confirm the resulting live configuration, and the
direct-push proof confirms enforcement rather than configuration alone.
